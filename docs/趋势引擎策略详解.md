# 趋势引擎策略详解

## 概述

趋势引擎（TrendEngine）是一个基于技术指标的自动化交易策略，主要使用简单移动平均线（SMA30）作为入场信号，结合多层次的风险管理机制来执行趋势跟随交易。

## 核心策略逻辑

### 1. 入场信号

策略基于价格与30周期简单移动平均线（SMA30）的相对位置来决定入场方向：

- **做多信号**：当价格从下方上穿SMA30时，执行市价买入
- **做空信号**：当价格从上方下穿SMA30时，执行市价卖出

```typescript
if (lastPrice > currentSma && currentPrice < currentSma) {
    await this.submitMarketOrder("SELL", currentPrice, "下穿SMA30，市价开空");
} else if (lastPrice < currentSma && currentPrice > currentSma) {
    await this.submitMarketOrder("BUY", currentPrice, "上穿SMA30，市价开多");
}
```

### 2. 入场频率控制

为防止过度交易，策略实施了严格的入场频率控制：

- **分钟级限制**：同一分钟内最多只允许一次入场
- **止损冷却期**：止损发生后60秒内禁止基于SMA信号再次入场

### 3. 风险管理体系

策略采用多层次的风险管理机制：

#### 3.1 基础止损

- 基于配置的损失限制（`lossLimit`）计算止损价格
- 在入场后立即设置止损单

#### 3.2 步进式锁盈

在动态止盈生效前，采用步进式锁盈机制：

- **触发条件**：当浮动盈利达到 `profitLockTriggerUsd` 时启动
- **移动规则**：盈利每增加 `profitLockOffsetUsd`，止损价就向有利方向移动一次
- **限制条件**：移动后的止损价不能超过动态止盈的激活价

#### 3.3 动态止盈

- **激活条件**：当盈利达到 `trailingProfit` 时激活
- **回调率**：使用 `trailingCallbackRate` 控制止盈回调幅度
- **执行方式**：设置TRAILING_STOP_MARKET订单

#### 3.4 强制止损

当亏损达到配置的损失限制时，策略会：

1. 撤销所有挂单
2. 执行市价平仓
3. 记录止损时间，启动冷却期

### 4. 价格保护机制

为防止在异常价格情况下平仓，策略包含价格保护：

- **滑点检查**：平仓时检查市价与标记价格的偏离程度
- **阈值控制**：超过 `maxCloseSlippagePct` 时拒绝平仓操作

## 配置参数详解

### 核心配置项

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `symbol` | string | "BTCUSDT" | 交易对符号 |
| `tradeAmount` | number | 0.001 | 每次交易数量 |
| `lossLimit` | number | 0.03 | 单笔交易最大损失（USDT） |
| `trailingProfit` | number | 0.2 | 动态止盈激活盈利（USDT） |
| `trailingCallbackRate` | number | 0.2 | 动态止盈回调率（百分比） |
| `profitLockTriggerUsd` | number | 0.1 | 步进锁盈触发盈利（USDT） |
| `profitLockOffsetUsd` | number | 0.05 | 步进锁盈移动步长（USDT） |
| `pollIntervalMs` | number | 500 | 策略轮询间隔（毫秒） |
| `maxCloseSlippagePct` | number | 0.05 | 最大平仓滑点百分比 |
| `priceTick` | number | 0.1 | 价格最小变动单位 |
| `qtyStep` | number | 0.001 | 数量最小变动单位 |

## 技术架构

### 1. 数据订阅

策略订阅以下实时数据：
- 账户信息（余额、持仓）
- 订单状态
- 深度数据（盘口）
- 实时价格（Ticker）
- K线数据（用于计算SMA）

### 2. 状态管理

- **订单锁机制**：防止重复下单
- **限频控制**：处理交易所API限制
- **交易日志**：记录所有操作和状态变更

### 3. 错误处理

- **网络异常**：自动重试和恢复
- **订单异常**：智能处理未知订单错误
- **限频处理**：遇到限频时暂停操作

## 策略优势

1. **趋势跟随**：基于技术指标，捕捉趋势行情
2. **严格风控**：多层次风险管理，控制单笔损失
3. **自动化执行**：无需人工干预，24小时运行
4. **灵活配置**：参数可调，适应不同市场环境

## 适用场景

- **趋势性市场**：在明显的上升或下降趋势中表现最佳
- **中等波动率**：适合波动率适中的交易品种
- **流动性充足**：需要良好的市场深度支持

## 风险提示

1. **震荡市风险**：在横盘整理行情中可能产生多次小亏损
2. **滑点风险**：极端行情下可能出现较大滑点
3. **技术风险**：依赖交易所API稳定性
4. **市场风险**：任何策略都无法完全避免市场风险

## 性能监控

策略提供实时监控指标：
- 当前持仓状态
- 浮动盈亏
- 累计盈亏
- 交易次数
- 会话成交量
- 策略信号状态

通过完善的日志系统和实时监控，用户可以全面了解策略运行状态并及时调整参数。
