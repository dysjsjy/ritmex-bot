# 做市引擎逻辑详解

## 概述

做市引擎（MakerEngine）是一个自动化做市策略实现，通过在买卖盘两侧同时挂单来提供流动性并赚取价差收益。

## 核心逻辑

### 1. 状态判断

引擎根据当前持仓状态决定挂单策略：

```typescript
const position = getPosition(this.accountSnapshot, this.config.symbol);
const absPosition = Math.abs(position.positionAmt);

if (absPosition < EPS) {  // 未持仓
    // 做市商模式：同时挂买单和卖单
} else {  // 已持仓
    // 平仓模式：只挂平仓单
}
```

### 2. 未持仓状态（做市商模式）

当账户没有持仓时，引擎会同时挂出买单和卖单：

```typescript
if (canEnter) {
    desired.push({ 
        side: "BUY", 
        price: bidPrice, 
        amount: this.config.tradeAmount, 
        reduceOnly: false 
    });
    desired.push({ 
        side: "SELL", 
        price: askPrice, 
        amount: this.config.tradeAmount, 
        reduceOnly: false 
    });
}
```

**价格计算：**
- **买单价格** = 当前最高买价 - `bidOffset`（配置的偏移量）
- **卖单价格** = 当前最低卖价 + `askOffset`（配置的偏移量）

### 3. 已持仓状态（平仓模式）

当账户有持仓时，引擎只挂平仓单：

```typescript
const closeSide: "BUY" | "SELL" = position.positionAmt > 0 ? "SELL" : "BUY";
const closePrice = closeSide === "SELL" ? askPrice : bidPrice;
desired.push({ 
    side: closeSide, 
    price: closePrice, 
    amount: absPosition, 
    reduceOnly: true 
});
```

**持仓方向判断：**
- **多头持仓**（`positionAmt > 0`）：挂卖单平仓
- **空头持仓**（`positionAmt < 0`）：挂买单平仓

## 风险管理

### 1. 止损机制

引擎包含自动止损功能：

```typescript
private async checkRisk(position: PositionSnapshot, bidPrice: number, askPrice: number): Promise<void> {
    const triggerStop = shouldStopLoss(position, bidPrice, askPrice, this.config.lossLimit);
    if (triggerStop) {
        // 触发止损，市价平仓
        await this.flushOrders();  // 先撤销所有挂单
        await marketClose(...);    // 然后市价平仓
    }
}
```

**止损流程：**
1. 检查是否达到止损条件
2. 撤销所有活跃挂单
3. 执行市价平仓

### 2. 价格追逐

引擎支持价格追逐功能，当市场价格变动超过阈值时自动调整挂单价格：

```typescript
const { toCancel, toPlace } = makeOrderPlan(availableOrders, targets, tolerance);
```

## 订单管理

### 1. 订单同步

引擎通过`syncOrders()`方法维护订单状态：

```typescript
private async syncOrders(targets: DesiredOrder[]): Promise<void> {
    const availableOrders = this.openOrders.filter(o => !this.pendingCancelOrders.has(o.orderId));
    const { toCancel, toPlace } = makeOrderPlan(availableOrders, targets, tolerance);
    
    // 撤销不匹配的订单
    for (const order of toCancel) {
        await safeCancelOrder(...);
    }
    
    // 挂出新的期望订单
    for (const target of toPlace) {
        await placeOrder(...);
    }
}
```

### 2. 订单状态跟踪

引擎维护多个状态集合来跟踪订单：

- `openOrders`：当前活跃的挂单列表
- `pendingCancelOrders`：待取消的订单ID集合
- `locks`：订单操作锁，防止重复操作
- `timers`：订单操作计时器

## 配置参数

### 核心配置项

- `tradeAmount`：每次交易的数量
- `bidOffset`：买单价格偏移量
- `askOffset`：卖单价格偏移量
- `priceTick`：价格最小变动单位
- `lossLimit`：止损阈值
- `priceChaseThreshold`：价格追逐阈值
- `refreshIntervalMs`：刷新间隔

## 优势与风险

### 优势
1. **自动化运行**：无需人工干预
2. **流动性提供**：为市场提供买卖盘流动性
3. **价差收益**：通过买卖价差获利
4. **风险管理**：内置止损机制

### 风险
1. **单边行情风险**：在趋势性行情中可能持续亏损
2. **流动性风险**：在市场深度不足时可能无法及时成交
3. **技术风险**：网络延迟、API限制等技术问题

## 使用建议

1. **选择合适的交易对**：选择流动性好、波动性适中的交易对
2. **合理设置偏移量**：根据市场波动性调整买卖偏移量
3. **监控运行状态**：定期检查引擎运行状态和盈亏情况
4. **设置适当的止损**：根据风险承受能力设置止损阈值

## 总结

做市引擎是一个典型的做市商策略实现，通过智能的持仓状态判断和风险管理，在提供流动性的同时实现稳定的价差收益。该策略适合在流动性较好的市场中运行，需要根据市场条件合理调整参数配置。

function getOrderStrategy(positionState: PositionState): OrderStrategy {

        case PositionState.NO_POSITION:

            }
    }
}

### 3. 主循环逻辑

```typescript
class MarketMakerEngine {
    private isRunning: boolean = false;
    private rateLimiter: RateLimiter;
    
    async mainLoop(): Promise<void> {
        // 如果循环正在运行，则跳过本次循环
        if (this.isRunning) {
            return;
        }
        
        // 速率控制
        if (!this.rateLimiter.canExecute()) {
            return;
        }
        
        this.isRunning = true;
        
        try {
            // 检查数据是否准备就绪
            if (!this.isReady()) {
                return;
            }
            
            // 获取当前持仓状态
            const positionState = this.getPositionState();
            
            // 根据持仓状态生成订单策略
            const strategy = this.getOrderStrategy(positionState);
            
            // 生成具体订单
            const orders = this.generateOrders(strategy);
            
            // 同步订单到交易所
            await this.syncOrders(orders);
            
            // 风险管理检查
            await this.checkRiskManagement();
            
        } finally {
            this.isRunning = false;
        }
    }
    
    private getPositionState(): PositionState {
        const position = this.currentPosition;
        return position && Math.abs(position.positionAmt) > 0 
            ? PositionState.HAS_POSITION 
            : PositionState.NO_POSITION;
    }
    
    private generateOrders(strategy: OrderStrategy): Order[] {
        const orders: Order[] = [];
        
        if (strategy.buyOrder) {
            // 生成买单
            orders.push(this.createBuyOrder());
        }
        
        if (strategy.sellOrder) {
            // 生成卖单
            orders.push(this.createSellOrder());
        }
        
        if (strategy.closeOrder) {
            // 生成平仓单
            orders.push(this.createCloseOrder());
        }
        
        return orders;
    }
}
```

### 4. 订单生成逻辑

```typescript
class MarketMakerEngine {
    private createBuyOrder(): Order {
        const bidPrice = this.calculateBidPrice();
        return {
            side: 'BUY',
            price: bidPrice,
            amount: this.config.tradeAmount,
            reduceOnly: false
        };
    }
    
    private createSellOrder(): Order {
        const askPrice = this.calculateAskPrice();
        return {
            side: 'SELL',
            price: askPrice,
            amount: this.config.tradeAmount,
            reduceOnly: false
        };
    }
    
    private createCloseOrder(): Order {
        const position = this.currentPosition;
        const closePrice = this.calculateClosePrice(position);
        return {
            side: position.positionAmt > 0 ? 'SELL' : 'BUY',
            price: closePrice,
            amount: Math.abs(position.positionAmt),
            reduceOnly: true
        };
    }
    
    private calculateBidPrice(): number {
        // 买单价格 = 当前最高买价 - 偏移量
        return this.currentBidPrice - this.config.bidOffset;
    }
    
    private calculateAskPrice(): number {
        // 卖单价格 = 当前最低卖价 + 偏移量
        return this.currentAskPrice + this.config.askOffset;
    }
    
    private calculateClosePrice(position: Position): number {
        // 平仓价格根据持仓方向决定
        return position.positionAmt > 0 
            ? this.currentAskPrice  // 多头平仓用卖价
            : this.currentBidPrice; // 空头平仓用买价
    }
}
```
